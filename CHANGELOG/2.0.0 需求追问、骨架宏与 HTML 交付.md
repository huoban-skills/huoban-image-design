# 2.0.0 需求追问、骨架宏与 HTML 交付

> 2026-09-16

出图流程分三段：先分轮追问把需求问清、拿到需求单确认；再由脚本产出页面外壳，模型只填槽位内容；交付单文件 HTML。整条流程在只有 Python 标准库、没有 Chrome 的沙箱里能跑完。

## 重点

1. **需求追问独立成篇**（references/intake.md）。四种消息依次发出、发完即停：定盘子 → 需求单初稿 → 逐图决定（每轮 3 张图）→ 终稿。只问决定，页面类型、端、版式、底色、数据口径由 skill 自己定。需求单固定四列：图名、内容、页面与端、决定与默认；初稿和终稿同一格式。题库问空、终稿没有"待问"、用户回了确认，三条齐了才动手画。

2. **页面骨架宏 `<hb-page kind=…>`**。产品壳、画布高度、栅格、浮层定位都由脚本产出，模型不再手写 `.stage`／`.window`。`expand.py --page kind` 一次给出槽位表、可用宏和最小示例；`<hb-screens>` 出 2～3 屏手机流程壳。顶层放错宏、缺必有宏直接报错并给可用清单。

3. **组件登记表是唯一名录**。类名对齐 huoban-page 官方组件 type，组件一律用登记表的官方中文名（标签页、按钮组件、透视表、流程执行记录、大屏指标框）。registry.py 三向校验登记表、结构文件与样式，并核对每个宏在 expand.py 里存在。

4. **六篇页面原则重写**，章节统一为 布局原则 → 组件选取 → 色彩 → 数据与文案 → 禁止项 → 检查清单。布局章开头是版式表：第一行默认版式，其余按判断顺序命中即用，每个版式一个判据。线框示意在 assets/layout-gallery.html（看板 3、大屏 1、工作台 3、详情页 2）。组件辞典按场景列官方组件的适用与举例，选图表类型时才读。

5. **交付物是 HTML**。PNG／SVG 由 export.py 按需导出，找不到 Chrome 只提示不下载。一批图放同一个文件夹，文件夹名用客户名或项目名，图名带两位序号。

6. **静态检查不依赖 Chrome**。check.py 纯标准库，按实测行高估算版面：自造组件与未定义 token、列丢行容器、待办竖叠、并排不等高、单卡拉伸、内容太少、PC 图里的手机组件、空态、浮层放左、浮层遮挡过头。提示里按页面类型列出这一栏还能补哪些组件，只补短的那一栏。`--acceptance` 起草十条人工验收表。

7. **骨架层按产品实测补齐**：字段组、多项统计、我发起的、表格列表、进度条、分类汇总、面积图、条形图、封面、动态、评论十一个宏；状态条两种形态；图表卡片与无卡片两种外壳。`<hb-col>` 让矮组件在一栏里竖叠，不再被拉高。

8. **数据大屏按官方样板重做**：不缩放的 24 栅格三列骨架，左右列对称，中央视觉位跨整列；五套主题只改 token，图表系列色固定；地图用网点阵占位，不画国界。

9. **营销浮层固定在底图右下角**，没有位置属性，右缘探出 200，宽 300～480，一定压住底图又不盖过四分之一。

10. **回归集**（九张宏片段＋一张手写表单编辑页）放在 skill 同级目录 huoban-image-design-tests/，regress.py 逐张拼装比对基线，并校验 macros.md 与 expand.py 同步。

## 其他

- 追问细节：一轮一条消息整轮发出，轮末给"按推荐就是 1A、2A…"供整轮采纳；漏答按推荐记不追问。题干里的数量是建议值，用户自己给的照做。看数那张图在清单题里固定出现并标推荐。
- 详情页版式两种：双栏式（默认，主栏字段与明细、侧栏数字或流程，栏宽 13＋11 或 16＋8）与单栏式（信息量很少）。各位置的组件由本图自己挑。
- 工作台按钮组件 4 个按钮以上独占一行，3 个以下与单指标或待办并排。表单编辑页只在用户点名时出图。
- 状态色统一红绿灯：完成绿、进行中与待办橙、异常红、未开始浅灰；配色并入视觉四原则。
- 看板追问过程指标 1～3 个、对比维度 1～2 个；透视表不限张数，靠布局排开。
- 浮层里的表最多 4 列，列宽按卡片等分。
- 删除：企业门户、dashboard-data-story.md、visual-components.md、一次性类名迁移脚本；实测记录移到 skill 外。

## 文件结构

```
SKILL.md                         六步流程；页面类型路由表带 hb-page kind
assets/
  base.css                       .stage.auto 画布、浮层栅格、骨架层组件
  registry.json                  官方 type ↔ 中文名 ↔ 类名 ↔ 宏 ↔ 采集状态
  c1～c5                         结构模板，带 data-type / data-cn / data-measured
  layout-gallery.html            各页面版式线框示意
scripts/
  expand.py                      hb-page 等骨架宏、槽位表、--page／--doc
  build.py / export.py           拼装；PNG／SVG 按需导出
  check.py                       静态检查、渲染检查、人工验收表
  registry.py / regress.py       名录校验；回归比对
references/
  intake.md                      需求追问与需求单
  principles/                    六篇页面原则＋组件辞典＋视觉四原则＋防重复
  canvas/                        营销与产品设计画布、检查与验收、导出
  macros.md                      由 expand.py --doc all 生成
```
