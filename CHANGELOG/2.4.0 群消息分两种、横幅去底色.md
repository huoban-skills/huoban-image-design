# 2.4.0 群消息分两种、横幅去底色

## 企微群消息分卡片消息和 markdown 消息

`hb-wxgroup` 一条消息写成 `!跟进助手` 是卡片消息，`!跟进助手 | md` 是 markdown 消息；换头像图标写 `!跟进助手 | md | bell`。

- 卡片消息：顶部小标题带虚线分隔，底部链接行上方有细线、右侧带箭头。
- markdown 消息：一段富文本，没有顶部小标题和分隔线，字段名加粗带冒号跟在同一行，底部链接是条纯蓝字。`^` 顶部小标题在 markdown 消息里会报错。

气泡固定 260 宽，右边留 51 的空隙。

## 横幅一律无底色、左对齐

`hb-banner` 去掉 `solid` 属性和 `.rich.title.bg-solid` 那档纯色底，写了 solid 会报错；整块背景图仍用 `card`。手机工作台横幅跟着改成无底色左对齐、页面名 20/600，不再是深色底居中。

## 工作台页签卡包住嵌进来的明细

`hb-wpage` 里写在 `tabs:` 之后的 `<hb-ocards bare>` 和 `sub:` 都收进同一张页签卡，不再各自成卡中间留缝。
