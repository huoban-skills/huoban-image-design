# 2.6.0 批量导出、浏览器探测、路径约定与出图前必查

> 2026-09-27

## 摘要

1. 新增：export.py 支持多张图一次导出，装了 Playwright 时整批只起一次浏览器
2. 修复：浏览器探测改为先问 Playwright 自己的 Chromium 路径，缓存目录兼容 Playwright 1.5x 的新结构
3. 变更：浏览器成为必需；找不到时 export.py 报错退出，check.py 报 Blocker `render-failed`
4. 变更：文档里的命令一律写成 `<skill>/scripts/…`，不依赖当前工作目录
5. 新增：SKILL.md 步骤 2「出图前必查」，列出展开时最常报错的六条

---

## 详情

### 1. 批量导出

`python3 <skill>/scripts/export.py 配图/*.html --png`，每张图出在各自同目录。原来每张图要冷启动两次 Chrome：一次量画布，一次截图。现在整批共用一个浏览器，本机 22 张图 32 秒导完，原来每张约 3 秒；出图尺寸不变。没装 Playwright 时逐张走 Chrome 命令行。`--out` 只能配一张图。

### 2. 浏览器探测

Playwright 1.5x 把 headless shell 的可执行文件改名为 `chrome-headless-shell`、macOS 上改成 `Google Chrome for Testing.app`，原来按目录结构猜的规则找不到，环境里有 Chromium 也会报找不到。现在的顺序：`CHROME_BIN` → Playwright 报告的 Chromium 路径 → Playwright 缓存目录（新旧结构都认）→ PATH 里的 chromium / chromium-browser / google-chrome / chrome / chrome-headless-shell → macOS 本机 Chrome。Playwright 自带的浏览器起不来时，改用探测到的浏览器。

### 3. 浏览器必需

本机和云端环境都有浏览器，渲染检查和 PNG 导出不再有「没有浏览器就跳过」的分支：找不到浏览器时 export.py 报错退出，check.py 报 Blocker `render-failed`，设 `CHROME_BIN` 后重跑。手动下载 chrome-headless-shell 的说明和 `HB_NO_CHROME` 开关一并删除。`--no-render` 仍可只做静态检查。

### 4. 路径约定

`<skill>` 指 SKILL.md 所在目录。SKILL.md、references 和脚本用法说明里的命令都写成 `<skill>/scripts/…`、`<skill>/assets/…`，在客户或项目目录下执行时也能找到脚本；脚本内部一律按自身位置定位 skill 目录。用法示例里的 `/tmp/…` 改成相对文件名。

### 5. 出图前必查

图标名要对 icons.svg、`<hb-tools>` 自定义工具要带图标、`size="slide"` 只用于营销类电脑端页面、手机组件只放手机页、有动作的列表要带 `操作:ops`、组件按槽位表放。这些 expand.py 都会报错，写片段时照做就不用返工。
