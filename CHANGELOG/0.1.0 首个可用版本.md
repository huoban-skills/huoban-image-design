# 0.1.0 首个可用版本

> 2026-08-09

---

## 详情

首个可用版本。产出"长得像伙伴云产品"的系统界面示意图：单文件 HTML 源 ＋ 2x PNG。

### 核心决策

- **结构与皮肤分离**。结构来自真实产品 DOM 实测，骨架样式只管尺寸布局，颜色全部走 CSS 变量由皮肤提供。换配色只动 token，不碰结构。
- **不自造组件**。伙伴云没有的控件、布局、交互形态一律不画；名录里有但未实测的形态，先告知用户再按实测尺寸仿写。
- **两种产出按用途分**。产品设计类＝纯界面图，撑满窗口、可照着在平台里搭建；营销类＝底层界面＋浮层补充说明，用于报告和讲解。

### 资产

**结构**（真实产品 DOM 实测，按页面类型按需读，禁止全读）
- `assets/c1-shell.html` — 产品壳、一级顶栏、左侧导航
- `assets/c2-table-form.html` — 视图页签、工具栏、数据表格、字段、表单、卡片视图、七种业务视图
- `assets/c3-page-detail.html` — 独立详情页、记录详情弹窗、工作台与数据分析组件、企业门户、内容组件

**样式**
- `assets/base.css` — 骨架样式。尺寸取自实测（顶栏 56、侧栏 248、行高 35、标签 20、按钮 32/24）
- `assets/skins/` — 10 套皮肤：产品原生蓝、藏蓝金、科技暗黑、温暖人文、高端黑金、活力紫、中式雅韵、安全红、北欧冷灰（Nord 色系）、柔和粉彩（Catppuccin Latte 色系）
- `assets/icons.svg` — 63 个图标的 symbol 雪碧图，线性与实色两类。做成静态 symbol 而非脚本注入，因为 SVG foreignObject 导出不执行脚本
- `assets/fit.js` — 画布自适应。全屏模式贴合窗口宽，画布模式只缩不放

**工具**
- `scripts/check.py` — 静态检查，零依赖。分级报告写死色值（Blocker）、自造组件（High）、本图独有类（Nit）、SVG 导出前置条件

**规范**
- `references/canvas-spec.md` — 画布规范与两条导出管线（2x PNG、SVG 嵌报告）
- `references/skin-guide.md` — 输入判定、皮肤选型、从品牌色造皮肤、Radix 12 级取色尺
- `references/principles/` — 8 份设计判据：视觉四原则、布局、配色、组件规范、交互三原则、看板数据故事、图表选型、防千篇一律

### 与其他 skill 的协作

- **huoban-solution-report**：报告皮肤与本库同名同气质。报告选定皮肤后，配图用同名皮肤，报告与图自动同色系。报告通过图需求单调用本 skill 出图，图落在报告项目的 `figures/`。

### 已知边界

- 长尾组件（内容组件、日历、看板、甘特）的骨架样式只有要点版，用到时按结构文件注释里的实测尺寸就地补写。
- 图表绘图区靠内联 SVG 手绘，颜色必须用 token；已在 `check.py` 里设为 Blocker 拦截。
- 尚无页面骨架模板（skeletons），常见页面仍从组件现拼。
- 尚无皮肤 showcase 图，选皮肤靠文字描述。

### 待办

- 页面骨架模板：常见页面从零拼改为填空
- 皮肤 showcase：让用户看图选而不是听描述
- 对比度校验并入 `check.py`
- 品牌色生成器：一个 hex 自动生成亮暗整套皮肤
