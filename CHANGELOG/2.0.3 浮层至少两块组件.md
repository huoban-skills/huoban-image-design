# 2.0.3 浮层至少两块组件

> 2026-09-18

画面浮层要真的是一块画面：至少两块组件，窗口框收细。

## 重点

1. **浮层至少放两块组件，只放一块直接报错。** 用 `<hb-row>`／`<hb-col>` 排成一小块画面，推荐三四块排两行，比如明细表配一张汇总图。

2. **窗口框收成一道细边。** 内边距从 16 改成 6，组件之间间距 8，框只起"这是另一屏"的提示作用，不再像一圈灰边套在卡片外。

3. **需求单浮层列写到组件。** 一句话写浮层放哪一屏的哪块画面，列出至少两块组件，如「来源补货申请：申请明细表＋按门店汇总柱状图」。
