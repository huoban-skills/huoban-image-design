# 2.3.0 企微消息分应用消息与群消息

企业微信的两种消息形态分开画：应用推给某个人的通知，和机器人发进业务群的卡片。

- `hb-chat` 改名 `hb-wxapp`，中文名「企业微信应用消息」：会话里只有这一个应用在说话，不出头像和发送者名。渲染不变，仍是仿写未实测。
- 新增 `hb-wxgroup` 企业微信群消息（2026-09-21 按群消息截图比例换算，非 DOM 实测）：左头像 32 ＋ 发送者名 ＋ 白卡气泡；卡内可放顶部小标题（带虚线）、大标题、居中大数字、灰底提示块、引用块、字段行（值加 `:link` 出主色）、底部「查看详情」链接行；属性 `chips` 出输入条上方的群机器人快捷入口，`noinput` 不画输入条。

需求单里提到企微通知时要先分清楚是哪一种：推给本人走应用消息，发进业务群走群消息。
