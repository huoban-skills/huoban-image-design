# 1.5.0 数据大屏

新增第五份结构文件：数据大屏。2026-09-04 实测 app.huoban.com 三类大屏页（客户搭的生产车间大屏、项目管理数字大屏，官方模板黑金金融、深青未来）：大屏＝自定义页面「超宽」模式＋深色＋整页背景图＋卡片装饰框，部件仍是看板那套。产品里的背景、标题条、装饰框都是搭建者上传的图片，本 skill 不带图，用 CSS 画等价几何。

- `assets/c5-screen.html`：架构「数据大屏」；组件大屏标题条、指标框、大屏图表卡、中央视觉位、进度条列表、播报表，尺寸来自实测（画布内距 20、栅格间距 20、指标框 159×100、标题条 80、图表卡标题条 40、卡片底黑 65%）。
- `assets/base.css` 数据大屏一节：`.screen` 在自身作用域内重写墨色/线色/卡底 token，既有部件放进去自动变深色；主题 theme-blue/teal/gold；装饰框 frame-bracket 四角括号 / frame-round 圆角发光 / frame-none；标题条 line / tag 斜切标签 / chevron 雁翎居中；24 栅格 sc-grid（sp-N、rs-N）。
- `assets/screens/`：四张生成的 SVG 背景（星空地球、城市夜景、科技网格、黑金菱格），无版权依赖；build.py 看到 bg-* 类自动以 data URI 注入。
- 宏：hb-screen、hb-skpi、hb-scard、hb-sbars、hb-svisual；图表用既有 hb-bar/line/donut 的 bare 输出。
- SKILL.md 路由表加「数据大屏 / 大屏模式看板」行；原则路由加数据大屏行；dashboard-layout.md 加「大屏模式」一节（Z 型一屏、四样各选一种、指标一行、视觉位占位）。
- check.py 放行 bg-* 类；extract_templates 收录 c5。

回归：同一份内容片段分别以科技蓝＋星空、黑金＋菱格、深青＋网格三种组合拼装，check.py 无新增问题。
