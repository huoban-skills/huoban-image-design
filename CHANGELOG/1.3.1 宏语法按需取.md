# 1.3.1 宏语法按需取

宏的语法说明从 references/macros.md 整读，改为按宏按需取：

- 每个宏的详细语法和示例挂在 scripts/expand.py 的 DOCS 里，与实现同处一文件。
- `expand.py --list` 打印通用写法＋宏目录（一宏一行，按页面类型分组）；`--doc 宏名…` 只打印指定宏；`--doc all` 生成 references/macros.md，该文件不再手改。
- SKILL.md 步骤 4 改为先 `--list` 定这张图用哪几个宏，再 `--doc` 取这几个。

读取量：整读 macros.md 约 4,190 token；改后列表页约 2,400、工作台约 2,600、手机双屏约 2,400（目录 1,370＋所用宏）。展开逻辑未动，六个回归片段展开结果逐字节一致。
