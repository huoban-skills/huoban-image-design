# 1.6.0 页面原则文档

> 2026-09-13

原则库从"课程稿分篇"改成"按页面类型分篇"，每类页面一篇，组件选取单独成篇，为后续骨架宏提供槽位来源。

## 摘要

1. 新增: 五类页面各一篇原则——列表和视图页、表单与编辑页、自定义详情页、工作台、看板／分析页／大屏，每篇含定位、组件选取、布局、数据与文案、禁止项、检查清单
2. 新增: 组件选取按分析场景重写，覆盖官方名录 38 个部件的用途、举例、边界；只在画工作台、看板、详情页时读
3. 优化: 三篇旧文件并入新文档后删除（dashboard-layout、visual-layout、interaction-principles），visual-components 只留按钮分级与页面层级
4. 修复: 按演示工作区页面配置校正——工作台横幅是 rich 大标题预设、待办是多项统计＋我处理的＋我发起的三块并排、大屏指标框 3 栏／图表卡 6 栏／中央 12 栏、详情页记录功能区默认包含
5. 新增: 结构文件每个模板加 `data-type`（官方部件 type）与 `data-cn`（产品名），`extract_templates.py --list` 显示官方名
6. 新增: 实测记录目录 `references/measured/`，页面原则里的产品事实以它为出处

## 详情

### 1. 新增: 五类页面各一篇原则

principles/ 下新增 list-view、form、item-detail、dashboard，workbench 重写。SKILL.md 原则路由表改为：所有图读通用四篇（视觉四原则与布局、色彩、组件规范、防千篇一律）→ 按页面类型读一篇 → 工作台／看板／详情页另读组件选取。

已定口径：单指标两类页统一 4～6 个只放一行；表单保持最多四列（结构补 cols-4 待做）；看板横幅一行高、指标行在首屏上半；工作台图表权重最低、首屏不放；横幅默认无背景、可纯色或背景图卡片，官方渐变卡片作备选；层次默认白底描边、官方白卡阴影作备选。

### 2. 新增: 组件选取按分析场景

dashboard-chart-selection.md 改前只有图表选型；改后按"发生了什么／为什么会这样／我该怎么办／让页面动起来／页面本身"分场景，每个场景先原则再组件表（官方名称、用途、举例、边界）。边界只写画面上体现得出来的，配置层边界指向 huoban-page。

### 3. 优化: 旧文件并入

| 改前 | 改后 |
| --- | --- |
| dashboard-layout.md | 并入 dashboard.md |
| visual-layout.md | 24 栅格、三种布局、留白并入 visual-four-principles.md；详情页一节并入 item-detail.md |
| interaction-principles.md | 导航命名、填写动线、反馈三层分别并入 workbench.md、form.md；平台配置能力不再收录 |
| visual-components.md 表单一节 | 并入 form.md |

### 4. 修复: 按页面配置校正

来源是 hac 读取演示工作区 9 个自定义页面、4 个详情页与 70 张表视图的配置（references/measured/erp-demo-2026-09-12.md）。改动：c5 头注与模板跨度 sp-4／sp-8／sp-16 改为 sp-3／sp-6／sp-12，hb-skpi／hb-scard／hb-svisual 默认跨度同步；c3 架构注释删去"不出现记录操作栏"旧句；登记表横幅映射改为 rich、待办子区映射改为 procedure_task。

### 5. 新增: 模板标注官方名

assets/c1～c5 共 119 个模板，39 个有官方部件的加了 `data-type` 与 `data-cn`；类名未改。
