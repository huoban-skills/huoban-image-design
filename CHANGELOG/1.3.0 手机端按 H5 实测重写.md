# 1.3.0 手机端按 H5 实测重写

此前 c4-mobile.html 与 base.css 手机端一节是按官方截图仿写的骨架，文件头明确标注"未实测"。本版以 2026-09-03 在 app.huoban.com 用安卓 UA、375×812 视口采集的 H5 真实 DOM 计算样式整体覆盖，不叠补丁。

## 采集范围（工作区「库存管理」，11 屏）

工作区首页、表格列表页（网格态与三槽卡片态、配快捷按钮）、卡片视图、视图切换抽屉、记录详情页、编辑页、新建页、企业级流程任务列表、流程任务办理页、自定义页面（工作台）。企业微信/公众号会话不是伙伴云界面，保留仿写并注明。

## 结构与样式（assets/c4-mobile.html、assets/base.css 手机端一节）

- 手机壳 375 宽（真实逻辑像素）、固定高 812；顶栏 44。
- 列表页三件套：视图条 48（视图钮 32＋条数＋切换/搜索 32 图标钮）、卡片列表（底 field-bg、卡片白 r6 pad 13 间距 8：标题 14/500、副标题 12、三槽等分字段、可选右侧 106×90 图片、快捷按钮 28 高 r14 主色实底）、底部工具栏 56；悬浮新建 48 圆、分页条 56。
- 记录页（详情/编辑/新建/任务办理共用）：标题 17/500、二维码链接、分组标题 15/700 居中、字段 label 15/.65 在上＋值框 341×40 r6（详情灰底、编辑白底）、字段间距 19；选项/成员/关联/图片/数值五种值变体；计算字段与本节点可编辑字段整块青绿高亮；子表页签容器；底部记录操作条 56、表单保存条 57、任务办理区 100。
- 流程任务列表：页签 48、筛选条 48、任务卡 pad 16 r6 带 0.5px 边与浅影、右下线框主色「办理 ▾」；应用页签栏 56。
- 工作台：部件 335 宽 r9 阴影 0 20 40、横幅 80、快捷方式两列、页签容器、流程任务子区。
- 删除臆造组件：审批流程条（apv）、主按钮＋提交说明（pbtn/hint）、表单卡片（fcard/mf）、门户首页（hcard/mcard）、统计榜单（stats2/lcard）。既有图内嵌的是拼装时的样式快照，不受影响；重拼时需按新结构改写片段。

## 宏（scripts/expand.py、references/macros.md）

手机端宏改为：hb-phone、hb-mhome、hb-vbar、hb-ocards（三槽＋按钮＋图片）、hb-mtool（list/obar/app 三态）、hb-rec（记录页含五种值变体、高亮、子表页签）、hb-fbar、hb-taskbar、hb-ptasks、hb-wpage、hb-chat、hb-conn。删除 hb-mtabs、hb-mform、hb-mbtn。

## 采集方法

内置浏览器手机预设（安卓 UA）打开 app.huoban.com 即得 H5 版；产品是 React Native Web＋antd-mobile，类名哈希无语义，用注入的探针按元素输出几何与计算样式；点击用 pointer 事件序列模拟，部分弹层需人工点。原始数据 92 行留在会话 scratchpad，未入库。
