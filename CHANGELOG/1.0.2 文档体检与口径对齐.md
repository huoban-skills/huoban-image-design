> 2026-08-28

1. 修复: canvas-spec 的 Chrome 说明还写着「内置分卷自动解压」，0.3.3 早已改成按需下载

3. 修复: README 的皮肤清单是 0.1.0 那份作废名单，1.0.0 已声明以目录为准但漏改了这一份
4. 修复: README 与 SKILL.md 的产出物落点互相矛盾
5. 优化: 横幅规则从三条压成两条，排版与背景规则收归 c3 注释

## 详情

### 1. 修复: canvas-spec 的 Chrome 说明与现实相反

导出命令上方的注释写「Linux 沙箱由 skill 内置分卷自动解压，无需下载」。0.3.3 已删除 `assets/chrome/` 分卷，改为 check.py 按需从 CDN 下载并缓存。chrome-env.md 和 check.py 都是新口径，只有这条注释留在旧世界，Linux 上照着找分卷会扑空。

### 2. 修复: 拼装顺序两处写反

SKILL.md 步骤 4 写「皮肤 css ＋ base.css ＋ 本图补充样式」，canvas-spec「组装方式」写「base.css → 皮肤 css → 本图补充样式」。base.css 里没有 `:root` 定义，眼下两种顺序渲染结果相同，但一旦 base.css 加入 fallback token 就会踩。

**改后**：顺序只由 SKILL.md 步骤 4 定义，canvas-spec 改为指向它，只保留本文件独有的两条约束（`.stage` 位置、不外链文件）。

### 3. 修复: README 的皮肤清单作废

README 写「10 套」并列出温暖人文、高端黑金、活力紫、中式雅韵、安全红、柔和粉彩等已删除的皮肤。1.0.0 已声明「皮肤以 `assets/skins/` 目录为准」，但漏改了 README 这一份。

**改后**：README 不再罗列清单，改为写明分组（6 套报告同名 ＋ 2 套功能皮肤）并指向 `skin-guide.md` 和皮肤目录，避免同一份清单再次过期。

### 4. 修复: 产出物落点自相矛盾

README 写「`图名.html` 和 `图名@2x.png` 成对落当前目录」，SKILL.md 的落点表写「PNG 在外、HTML 进 `源文件/`」。README 改齐 SKILL.md。

### 5. 优化: 横幅规则压缩

步骤 4 里横幅占了 11 条中的 3 条，且第 9 条一句话同时写左对齐、默认无背景、`bg-solid` 和禁止纹理四件事。

**改后**：SKILL.md 只留两条——「第一屏必须放横幅组件」和介绍文案的写法；排版、背景、按钮位置三项规则收归 c3 横幅组件的 `data-measured` 注释，成为单一真相源。

### 6. 其他 stale 修正

- 图标数 63 → 64（`icons.svg` 实际 `<symbol>` 数），SKILL.md 与 README 两处
- 「c1～c3」补为「c1～c4」：SKILL.md 的 template 说明、skin-guide 开头、canvas-spec 验证第 3 条。c4-mobile 文件头那句「PC 端的 c1～c3 仍是实测真相源」是正确表述，不改
- README 架构图补上 c4-mobile 一层，并标明 PC 端为 DOM 实测、手机端为按官方截图仿写
- README 的 `CHANGELOG.md` 链接改为 `CHANGELOG/` 目录
- 硬约束里的「名录（18 类 70 项）」补上来源，写明与结构文件的 `data-component` 不是同一份计数
