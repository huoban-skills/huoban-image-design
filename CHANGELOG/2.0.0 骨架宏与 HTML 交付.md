# 2.0.0 骨架宏与 HTML 交付

> 2026-09-14

出图流程从"模型手写外壳与样式"改成"模型只填槽位内容，脚本产出外壳"，交付物从 PNG 改为单文件 HTML，整条流程在只有 Python 标准库、没有 Chrome 的沙箱里也能跑完。

## 摘要

1. 新增: 页面骨架宏 `<hb-page kind=…>`——外壳、画布高度、浮层定位、栅格由脚本产出，模型不再手写 .stage/.window/.page 和 .stage{height}；`--page kind` 一次给出槽位表、可用宏与最小示例
2. 优化: 组件类名对齐 huoban-page 官方组件 type（chart_single、tabs、rich、header_card…），登记表 registry.json 成为唯一名录，registry.py 三向校验
3. 优化: 交付物改为 HTML；PNG／SVG 由 export.py 按需导出，找不到 Chrome 只提示不下载；check.py 纯标准库，无 Chrome 时明说"渲染检查未执行"而不是打勾
4. 新增: 槽位校验与规模提示——顶层放错宏、缺必有宏直接报错并给可用清单；单指标个数、表格行数、浮层卡数超出约束给提示
5. 优化: check.py 堵自造组件通道（本图样式里的新类默认 High）、新增未定义 token 检查、报错带候选名；`--acceptance` 起草十条验收表
6. 优化: SKILL.md 收成七步流程；references/canvas 三份导出文档合并为 export.md
7. 新增: tests/ 回归集（永铭六张宏片段）与 regress.py；migrate_classes.py 把旧片段迁到新类名

## 详情

### 1. 新增: 页面骨架宏

expand.py 新增 hb-page / hb-row / hb-float / hb-duo 四个宏和 PAGE_SLOTS 槽位表。槽位顺序逐字来自 references/principles/ 五篇页面原则的"固定顺序"。

| 改前 | 改后 |
| --- | --- |
| 模型写 `.stage{height:624px}`、`.mk-float{top;width}`、`<div class="stage has-float"><div class="window theme-band">…` 共 40 余行外壳 | `<hb-page kind="workbench" ws="…" page="…">` 一行，体内按槽位写宏 |
| 浏览器渲染后回填 .stage 高度 | `.stage.auto` 按内容撑高；浮层进栅格（窗口 1440 ＋ 浮层 200），高度自动包含浮层 |

base.css 新增 `.stage.auto` 一节与 `.w-row > .span-N` 比例分配；1.x 手写外壳的图仍按旧规则渲染。

### 2. 优化: 类名对齐官方组件

migrate_classes.py 按整词替换 520 处（base.css、c1～c5、expand.py、check.py、references），永铭六张回归图改名前后逐字节一致。横幅从 `w-banner` 改为 `rich title`（官方 rich 组件的"大标题"预设），与"大幅富文本"`rich hero` 分开；大屏前缀 `sc-*` 改 `screen-*`；手机端改 `m-*`；表格页视图改 `view-*`。歧义记号（row、group、sub、fi、tag、editing、modal-mask）不改。

### 3. 优化: HTML 交付与沙箱

export.py：`--png` 自量画布高度（营销类透明底 1704×(高+96)，产品设计类边到边），`--svg` 用标准库做 foreignObject 封装并校验 XML，`--probe` 供 check.py。check.py 不再在导入时探测和下载 Chrome。

### 4. 新增: 槽位校验与规模提示

| 情况 | 结果 |
| --- | --- |
| 工作台顶层放了 hb-filters | 报错：顶层不能放，可用清单＋"放进 hb-tabcard 或页面末尾" |
| 缺 hb-banner | 报错：工作台必有，给顺序 |
| hb-row spans 加起来不是 24、段数与组件数不等 | 报错 |
| 单指标两组、透视表 >2、横幅两次、浮层卡 >2、一行 >4 组件 | 提示（不阻断） |

### 5. 优化: check.py

规则变化：`local-only-class` Nit → `local-class` High（`--allow-local` 降级）；新增 `unknown-token`、`scale-limit`、`tabs-nested`；`stage-no-height` 只对手写外壳生效；`unknown-component` 附 difflib 候选。

### 6. 优化: 文档

SKILL.md 步骤：定样式 → 需求单闸门 → 写骨架片段（`--page`／`--doc`）→ build → 对照判据 → check 与验收 → 交付 HTML（PNG／SVG 可选）。chrome-env.md、canvas/report-embed.md 并入 canvas/export.md 后删除。
