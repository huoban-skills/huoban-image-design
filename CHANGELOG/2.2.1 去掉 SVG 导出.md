# 2.2.1 去掉 SVG 导出

> 2026-09-22

## 重点

**只留 PNG 一种图片产出。** SVG 当初是给没有 Chrome 的沙箱兜底的（把 `<style>`＋`.stage` 包进 `<svg><foreignObject>`，纯文本拼接，不依赖渲染器）。现在执行环境基本都有 Chrome，这条分支用不上了，留着就是两套导出口径和两份文档。

删掉的：`export.py` 的 `export_svg()` 与 `--svg` 参数、`export.md` 的「SVG（嵌报告）」整节、SKILL.md 与 README 里的 `PNG／SVG` 口径。`--png` 和 `--probe` 不变。

## 影响

找不到 Chrome 时的出路只剩两条：装 Chrome（`export.py` 的提示里有 chrome-headless-shell 的下载命令），或直接交 HTML——HTML 本来就是默认交付物。

上一版（2.1.0）刚修好的 SVG CDATA 问题随这次删除一并作废；base.css 注释里的裸 `<` 不再有任何影响。
