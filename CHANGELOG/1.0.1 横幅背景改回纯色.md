# 1.0.1 横幅背景改回纯色

> 2026-08-28

---

## 详情

- **几何纹理配方整套下线**：`bg-grid`／`bg-ring`／`bg-aurora`／`bg-mesh`／`bg-soft` 从 base.css 删除。深色底压网格、环纹、斜纹、点阵的横幅实际做出来并不好看（潘达报告的看板配图为证），一块干净纯色都比它强
- **要背景只剩一套 `bg-solid`**：主色深底＋白字，无任何纹理。默认仍是无背景，标题靠字号（30/600）和留白立住
- SKILL.md 拼装步骤与 c3 横幅组件注释同步改写；base.css 注释写明纹理装饰已废弃，别再加回来
- `--banner-bg` 渐变 token 仍在用（大幅富文本 hero、日期时间组件、企业门户、手机端横幅卡），不受影响
