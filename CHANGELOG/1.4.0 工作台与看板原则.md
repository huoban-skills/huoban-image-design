# 1.4.0 工作台与看板原则

新增两份设计原则，填上此前只有一句话的工作台定位和只有图表选型的看板布局：

- `references/principles/workbench.md`：工作台是一个角色的工作入口；按角色的问题选部件（横幅、快捷入口、待办、页签容器、日历、我的数据、指标、门户型才放的快捷表单与公告）；首屏顺序横幅 → 快捷入口与待办同屏 → 页签/数据 → 指标；单指标一行、整页两屏上限；不放分析图。
- `references/principles/dashboard-layout.md`：指标类型到部件的映射（结果指标一行单指标、过程指标走进度条/统计表、趋势图左侧最大、环图并排、明细放底）；倒金字塔区块顺序对应三问。
