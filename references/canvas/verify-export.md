# 验证与导出（步骤 6 读）

## A. 机检

```bash
python3 scripts/check.py 图.html
```

**Blocker 必须清零**，High 逐条处理，Medium 逐条判断。几条容易误读的：

- `empty-gap` 只看布局层——组件之间、组件到画布边缘不许有大片空白；组件内部（图片格、列表行数、卡片字段）的留白由数据量决定，属于产品原样，不算问题。
- `column-uneven` 量同一栅格行里各栏的底部落差，超过 24px 报 Medium（阈值按肉眼实测定：37px 的落差人眼已经能看出来）。两栏之间的落差目检容易被「左右各自都很整齐」的错觉盖过去。修法是给短的那栏补数据行（分组行、明细行）或调整两栏栅格宽度，不要用固定高度硬撑。
- `content-clipped`（窗口内容比窗口高，底部被裁，整图观感偏下）和 `float-out`（浮层探出画布）都是 High。回填 `.stage` 高度时注意鸡生蛋：详情页画布 min-height 跟着窗口高走，先把 stage 填大再量会得到虚高——以「功能区 56＋画布内容实高＋边框 2」为准，量完改高（改 `--extra-style` 后重跑 `build.py`）再复量一次确认 `scrollHeight ≤ clientHeight`。
- `banner-person-name` 是横幅写成了具体某个人，改成角色名。

## B. 人工验收表

机检管不了语义——浮层里的内容是不是底层已经有的、该讲的东西丢没丢、数据像不像真的，这些只能看。**每张图逐条过一遍并把结论写出来，写不出结论就是没验。**

| # | 检查项 | 判据 |
| --- | --- | --- |
| 1 | 需求单落全 | 确认过的画布类型、页面类型、字段与数据都在图上；用户点名要的部件（工作台、看板、页签、统计区）一个不少 |
| 2 | 组件都是真的 | 名称与交互形态对得上 `assets/c1～c5` 名录，没有自造控件 |
| 3 | 层次关系对 | 每个组件是"白卡浮在灰底"还是"透明融进容器"，逐一对照结构文件的 `data-measured` 注释。出现"某条工具栏/筛选条颜色和邻区不一致"的观感，先怀疑缺了容器层（如 `.view-box`），不要改颜色硬凑 |
| 4 | 对齐与选型 | 列数一致、不定高不独占行、状态色走红绿灯语义、按钮分主/次/警示/置灰、图表选型对 |
| 5 | 浮层不重复底层 | 浮层里的卡片、字段、统计、表格，底层都没出现过。要强调底层已有的内容，调底层自身的对比关系，不画第二份 |
| 6 | 浮层底下是完整页面 | 把浮层遮住看底层，仍是一张能独立成立的页面；没有为给浮层腾位置而裁短窗口造成的底部缺失或空白 |
| 7 | 浮层没挡关键内容 | 左探出时工作区名、当前导航项、底部条要露出来；不压住这张图本来要讲的那个字段或那一行 |
| 8 | 信息密度够 | 列表有足够行数、看板指标成组、页签内容填实，不是三两行凑数 |
| 9 | 数据像真的 | 编号有规则且不连号、金额有零头、日期不等距、同一人重复出现、状态分布不均匀 |
| 10 | 整体观感 | 浏览器打开渲染后截图目检：高度贴合、无溢出、无大片空白、字号层级正常 |

交付前按这个格式逐图回报，一图一段：

```
验收 05-律师工作台
1 需求单落全 通过
2 组件都是真的 通过
3 层次关系对 通过
4 对齐与选型 通过
5 浮层不重复底层 改过：浮层原本复制了底层的收支统计，换成回款跟进记录
6 浮层底下是完整页面 通过
7 浮层没挡关键内容 改过：浮层上移 40px，露出案件过程的附件字段
8 信息密度够 通过
9 数据像真的 通过
10 整体观感 通过
```

三条纪律：

- **不合格的写清改了什么**，只写"改过"不算。
- **不写总括句**——"已按清单检查""均无问题"这类都不是结论，十条要一条条落。
- 有一条没过就不交付，改完重新回报那一条。

## 导出 2x PNG（默认交付物）

```bash
# CHROME 取法见 references/chrome-env.md（macOS 用本机 Chrome；Linux 沙箱由 check.py 按需下载并缓存复用）
"$CHROME" \
  --headless --screenshot=out.png \
  --window-size=<宽>,<高> --force-device-scale-factor=2 \
  --hide-scrollbars "file:///路径/图.html"
```

- 产品设计类：`1640,<stage高>`；营销类：`1704,<stage高+96>` 加 `--default-background-color=00000000`（细节见各自画布文件）。
- 透明底只适用于 PNG 走 HTML 的路径；SVG/foreignObject 嵌报告管线仍须垫不透明 rect（见 [report-embed.md](report-embed.md)），否则手机端 PDF 渲成灰块。
