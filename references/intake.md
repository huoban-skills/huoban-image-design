# 需求追问与需求单（步骤 1 读）

拿到出图需求先追问，需求单确认后才写骨架。问法照 grilling：分轮问，每轮只问前提已定的维度，每问编号并给推荐答案，等用户答完再问下一轮。用户在需求或材料里已经说清的维度标"已定"不再问；给了默认值的维度，用户不表态就按默认。不问数据：默认没有工作区，字段名和数据按材料里的行业自己编，编得像真的。

## 三轮维度

### 第 1 轮（任何图都问）

| 维度 | 问什么 | 推荐／默认 |
| --- | --- | --- |
| 画布类型 | 这张图给谁看、干什么用：放进报告或讲给客户听，还是用户要照着搭 | 来自建议报告或讲解材料 → 营销类；用户要搭 → 产品设计类。用户不定不猜 |
| 页面类型与端 | 画哪类页面（列表页／表单／详情页／工作台／数据看板／大屏）、PC 还是手机、一张还是一组 | PC；一组图时每张强调点要不同 |
| 角色 | 这页给哪个角色用（库管、销售、店长、审批人） | 材料里出现的主要角色；"给所有人"要追问到一个角色 |
| 样式 | 沿用项目已有样式、按行业推荐、还是新造 | 按 [skin/routing.md](skin/routing.md) 判定输入物：带样式的输入物问是否沿用，不带的给首选＋备选；报告已选皮肤直接同名 |

### 第 2 轮（按页面类型分支，只问命中的一支）

| 页面类型 | 问什么 | 推荐／默认 |
| --- | --- | --- |
| 列表页 | 视图形态：网格、看板、日历、甘特 | 网格。筛选、工具栏、列字段按行业默认，不问 |
| 表单 | 展示哪些字段、怎么分组、有没有子表 | 按行业常见单据给一版分组让用户改；只有弹窗一种，新建与编辑同一形态 |
| 详情页 | 这是哪条记录、有没有流程或状态流转、有没有明细子表、页签怎么分 | 页签按"详情 → 明细 → 过程"分 |
| 工作台 | 这个角色一天要发起什么、要处理什么、参不参与流程 | 参与流程 → 待办三块；不参与 → 不放待办 |
| 数据看板／大屏 | 结果指标、过程指标、对比维度（见下） | 每类 3～5 个，先做最核心的。筛选范围、引导式还是探索式自己定，不问 |
| 手机端 | 把上面命中的那一支问一遍 | — |

看板三项指标怎么问：

| 指标 | 问法 | 例 |
| --- | --- | --- |
| 结果指标 | 你越大越好或越小越好的数字是什么 | 销售额、目标完成率、按时交付率、良品率 |
| 过程指标 | 达成它要经过哪几个环节，各环节用什么数字衡量（顺利推进＝转化率类，推进快慢＝时间类，异常分支＝风险类） | 线索转化率、首次响应时间、原料合格率 |
| 对比维度 | 谁对这个指标负责，按什么切片比 | 人员、区域、产品、渠道、批次 |

三项缺一个链路就断：只有结果没有过程，看到问题找不到原因；过程指标必须从结果指标拆出来；缺对比维度，整体持平也看不出哪个团队暴跌。

### 第 3 轮（依赖前两轮）

| 条件 | 问什么 | 推荐／默认 |
| --- | --- | --- |
| 营销类 | 浮层要突出什么（只能是底层没有的内容） | 按材料里的卖点选一个 |
| 营销类且手机端 | 讲几步流程（1～3 屏）、每屏是哪一步、哪一屏是企微会话 | 只看一个页面 → 1 屏；有"从哪来到哪去" → 2 屏；超过 3 步拆两张图 |
| 自定义页面（工作台／看板／详情页） | 横幅：无背景／纯色／背景图卡片；层次：白底描边／浅底白卡 | 无背景；白底描边。一句话确认 |
| 任何图 | 数据文案：数字量级、时间范围、人名公司名要不要脱敏 | 按材料里的规模；近一个月；人名用常见姓名 |

## 问法格式

```
❓ Q1 - 画布类型：这张图是放进方案报告讲给客户听，还是客户要照着在伙伴云里搭？
➡️ 材料是建议报告，推荐营销类。

❓ Q2 - 页面类型：……
➡️ ……
```

## 需求单

三轮问完，汇成一张需求单让用户确认；多张图列成一个清单一次确认。**没拿到确认不进入步骤 2。** 格式对内对外一致，huoban-solution-report 的调用也是这个格式：

```
图名：库管工作台
画布：营销类 ｜ 页面：工作台（PC） ｜ 角色：库管 ｜ 皮肤：晨光蓝
内容：发起——扫码出库、扫码入库、盘点；处理——出库审批待办；参与流程
形态：横幅无背景；层次白底描边；浮层突出"扫码出库后库存实时变化"
数据：近一个月；数量级百件；人名常见姓名
```

手机竖图嵌报告时限宽居中（约 360px），需求单里注明。
