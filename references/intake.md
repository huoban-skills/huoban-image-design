# 需求追问与需求单（步骤 1 读）

读材料，材料已交代清楚的记为事实，没交代的按下面三轮提问。每一题都是用户日常会做的选择，选项从材料和行业惯例给，不问"颗粒度""维度"这类分析词。推荐项放 A 并标（推荐），用户不表态就按它。不问数据：默认没有工作区，字段名和数据按材料里的行业自己编，编得像真的。

## 三轮维度

### 第 1 轮（任何图都问）

| 顺序 | 定什么 | 问法示例 |
| --- | --- | --- |
| 1 | 画布类型 | 这张图用在哪？A 放进方案报告讲给客户听（推荐） B 客户要照着在伙伴云里搭 |
| 2 | 页面类型与端、张数 | 画哪个页面？A 库管工作台（推荐） B 库存看板 C 出库单详情页 D 其他（请补充）；PC 还是手机？一张还是一组？ |
| 3 | 角色 | 这页给谁用？A 库管（推荐） B 仓库主管 C 采购 D 其他（请补充） |
| 4 | 样式 | 按 [skin/routing.md](skin/routing.md) 判定输入物：带样式的问是否沿用；不带的给首选＋备选＋自定义；报告已选皮肤直接同名不问 |

页面类型题的选项从材料里出现的页面写，让用户一眼看出画哪个。"给所有人"要追问到一个角色。

### 第 2 轮（按页面类型分支，只问命中的一支）

| 页面类型 | 定什么 | 问法示例 |
| --- | --- | --- |
| 列表页 | 视图形态 | 物资档案用哪种视图？A 网格表格（推荐） B 按状态分列的看板 C 按日期的日历 D 甘特。筛选、工具栏、列字段按行业默认，不问 |
| 表单 | 展示哪些字段、怎么分组、有没有子表 | 出库单弹窗分几组？A 基本信息 ＋ 出库明细子表 ＋ 审批信息（推荐） B 只放基本信息 C 其他（请补充）。只有弹窗一种，新建与编辑同一形态 |
| 详情页 | 这是哪条记录、有没有流程或状态流转、有没有明细子表、页签怎么分 | 出库单详情要不要显示审批进度？A 要，顶部放步骤条（推荐） B 不要。明细子表放哪？A 页签"出库明细"（推荐） B 平铺在字段下方 |
| 工作台 | 这个角色一天要发起什么、要处理什么、参不参与流程 | 库管每天从这页发起什么？A 扫码出库、扫码入库、盘点（推荐） B 只有出入库 C 其他（请补充）。要处理什么？A 出库审批待办（推荐） B 不参与审批，只看自己的单 |
| 数据看板／大屏 | 结果指标、过程指标、对比维度（见下） | 每类 3～5 个；筛选范围、引导式还是探索式自己定，不问 |
| 手机端 | 把上面命中的那一支问一遍 | — |

数据看板三项指标的问法，选项从材料里的业务数字给：

| 指标 | 问法 | 选项来源 |
| --- | --- | --- |
| 结果指标 | 你越大越好或越小越好的数字是哪几个？A 出库及时率、库存周转天数、盘点差异率（推荐） B 其他（请补充） | 销售额、目标完成率、按时交付率、良品率 |
| 过程指标 | 达成它要经过哪几个环节，各环节看什么数？A 审批时长、拣货时长、复核差错数（推荐） B 其他（请补充） | 顺利推进＝转化率类，推进快慢＝时间类，异常分支＝风险类 |
| 对比维度 | 按什么切片比？A 按仓库（推荐） B 按业务员 C 按物资类别 D 其他（请补充） | 人员、区域、产品、渠道、批次 |

三项缺一个链路就断：只有结果没有过程，看到问题找不到原因；过程指标必须从结果指标拆出来；缺对比维度，整体持平也看不出哪个团队暴跌。

### 第 3 轮（依赖前两轮）

| 条件 | 定什么 | 问法示例 |
| --- | --- | --- |
| 营销类 | 浮层突出什么（只能是底层没有的内容） | 浮层强调哪个卖点？A 扫码出库后库存实时变化（推荐） B 审批一键通过 C 其他（请补充） |
| 营销类且手机端 | 讲几步流程（1～3 屏）、每屏哪一步、哪屏是企微会话 | 手机图讲几步？A 两步：企微收到待办 → 点开审批（推荐） B 一步，只看审批页 C 三步：企微通知 → 审批 → 出库单已生成。超过 3 步拆两张图 |
| 自定义页面（工作台／看板／详情页） | 横幅形态、层次 | 横幅要不要背景？A 无背景（推荐） B 纯色 C 背景图卡片。层次？A 白底描边（推荐） B 浅底白卡 |
| 任何图 | 数据文案：数字量级、时间范围、脱敏 | 数字按什么规模编？A 月出库几百单（推荐） B 几千单 C 其他（请补充）。人名？A 常见姓名（推荐） B 用材料里的真实姓名 |

## 问法格式

有选择框工具（如 AskUserQuestion）就用工具，一道提问一道题；没有就用文字版，每个选项单独一行：

```
出图前先确认几点：

1. {问题}？
   A. {推荐项}（推荐）
   B. {选项}
   C. 其他（请补充）

2. ...
```

每题不超过 4 个选项，末项留"其他"。一轮把当轮问题全部问完，一轮不超过 5 题；用户答完若引出新问题（选了"其他"、回答与材料矛盾），再问一轮，直到没有待明确的项才汇需求单。

## 需求单

三轮问完，汇成一张需求单让用户确认；多张图列成一个清单一次确认。**没拿到确认不进入步骤 2。** 格式对内对外一致，huoban-solution-report 的调用也是这个格式：

```
图名：库管工作台
画布：营销类 ｜ 页面：工作台（PC） ｜ 角色：库管 ｜ 皮肤：晨光蓝
内容：发起——扫码出库、扫码入库、盘点；处理——出库审批待办；参与流程
形态：横幅无背景；层次白底描边；浮层突出"扫码出库后库存实时变化"
数据：近一个月；月出库几百单；人名常见姓名
```

手机竖图嵌报告时限宽居中（约 360px），需求单里注明。
