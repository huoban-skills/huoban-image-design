# 数据大屏

本文用于画数据大屏：投在会议室或车间大屏上、让人远看的一屏页面，指标与图表规则同看板（[dashboard.md](dashboard.md)），本文只写大屏另加的版式、组件与视觉。只在用户明确要"大屏／大屏模式"时做，报告配图默认浅底看板。用法：先按第 1 节排骨架，再按第 2 节配组件，第 3 节定主题与配色。

## 1. 布局原则

### 版式

官方样板的骨架；不缩放，24 栅格、行高 20h−20、间距 20 与其他页面一致，画布 1640 宽、排下来 1440 高。

| 位置 | 栅格 | 放什么 |
| --- | --- | --- |
| 标题行 | 24×5 | 左上企业名 3 ＋ 大标题 18 ＋ 右上时间 3 |
| 分隔条 | 24×2 | 装饰 |
| 左列 | 6 栏，38 行 | 指标框 ×2 各 3×6 → 面积图 6×16 → 饼图 6×16 |
| 中列 | 12 栏，38 行 | 中央视觉位跨整列 |
| 右列 | 6 栏，38 行 | 进度条 6×12 → 对比图 6×26 |
| 底部 | 24 通栏 | 折线图 12×26 ＋ 表格列表 12×26 |

三列各自组件行数之和等于列高，三列才等高。变体：三列压成 5｜14｜5 并去掉指标框；顶部整块换成页签容器当标题容器。

## 2. 组件选取规则

按位置取组件，组件名是登记表里的大屏条目：

| 位置 | 组件 | 必有／可选 | 数量与取舍 |
| --- | --- | --- | --- |
| 标题行 | 大屏标题行（富文本大标题＋企业名＋时间组件） | 必有 | 1；标题写业务域，不写人名 |
| 分隔条 | 大屏分隔条（装饰） | 必有 | 1 |
| 三列 | 大屏分栏 | 必有 | 左 6｜中 12｜右 6，或 5｜14｜5 |
| 结果指标 | 大屏指标框（单指标） | 可选 | 2～8 个，每个带对比或趋势 |
| 趋势、构成、对比 | 大屏组件卡承载面积图、饼图、折线图、双轴图或柱状图 | 必有 ≥3 张 | 左列 2 张、右列 1 张、底部 1 张；图型选法查 [component-guide.md](component-guide.md) 四章 |
| 中央视觉位 | 大屏中央视觉位 | 必有 | 1，跨中列整高；客户的地图或 3D 图，否则网点阵占位或线框地球 |
| 环节达成 | 大屏进度条 | 可选 | 1 张卡 3～5 条 |
| 明细 | 大屏表格列表 | 可选 | 底部 1 张，8～10 行填满 |

不放的组件：横幅、筛选、按钮组、待办、快捷表单、页面封面。选图表类型或拿不准该用哪个组件时，查 [component-guide.md](component-guide.md)。

## 3. 色彩

| 项 | 规则 |
| --- | --- |
| 主题 | 五选一：cyan 深青未来（默认）、blue 蓝色科技、gold 黑金金融、red 红色党建、light 青色自然（浅色）；一张图只用一种；五套只差底色、描边、角标色、光带色和文字明暗 |
| 背景 | 主题底色 ＋ 细网格纹理 ＋ 顶部光带；不用发光、滤镜和专用字体 |
| 卡片 | 直角、半透明底、1px 描边、四角 L 形角标 |
| 标题条 | 40 高，左侧斜切铭牌 ＋ 右侧渐弱斜纹 |
| 文字 | 四档：主标题 30/700、指标值 32/500、组件标题 16/500、标签 14；白字两档 85%／45% |
| 图表系列色 | 五主题相同：主色 #5DA8E9、次色 #B6C7D5，饼图六档灰蓝，进度条蓝／橙／绿／红轮转；全部走 `--screen-*` token |
| 中央视觉位 | 客户给了地图或 3D 图就放进去；没有就用网点阵占位（深色底 ＋ 网点 ＋ 几个发光标记点，标题写「区域分布」）或线框地球；都不画国家与省份轮廓，不画灰图标 |

## 4. 数据与文案

- 指标值大字要带单位与对比，量级分散，不要一排都是万元。
- 表格列表要填满卡片，行数不够补到 8～10 行；状态列带异常态。
- 标题行写业务域（"物资运营数据大屏"），企业名放左上，时间放右上。
- 数据毛边规则见 [anti-sameness.md](anti-sameness.md)。

## 5. 禁止项

- 大屏一张图里混用两种主题，或自己另造一套卡片框与标题条。
- 画国家或省份轮廓、灰图标占位。
- 用发光、滤镜或专用数字字体。

## 6. 检查清单

逐图回答"通过／改过（改了什么）"。

1. 只用一种主题。
2. 三列的行数之和相等、底边齐。
3. 中央视觉位 12 栏跨满主体。
4. 图表系列色是固定的那组。
