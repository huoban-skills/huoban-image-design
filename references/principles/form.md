# 普通表单与表单编辑页

依据：huoban-table 表单布局文档与 huoban-table-blueprint 的表单原则、生态训练营课程判据、assets/c2 结构。表单弹窗与编辑态的尺寸尚未实测，文中已标出。字段类型名以 huoban-table 字段目录为准。

## 1. 定位

- 表单是新建或编辑一条记录的界面，三种形态：创建或编辑表单弹窗（表名＋取消／保存并继续／保存＋字段区）、标准表单编辑态（记录标题＋取消／保存＋字段分组）、页面里的快捷表单部件（快捷表单，放在工作台或详情页里就近录入）。前两种只在用户明确要求时画。
- 表单的目标是让人从上到下一条直线填完：需要手填的靠左，能自动的靠右或不出现。
- 边界：字段在详情页里的只读展示见 [item-detail.md](item-detail.md)；表单在页面里作为部件时的取舍见 [workbench.md](workbench.md)。

## 2. 组件选取规则

### 字段类型与展示形态

产品字段类型 22 种；示意图里常用 17 种：单行文本、手机号、多行文本、选项（展开型／下拉型）、富文本、条码、日期和时间、数值、金额、单成员、多成员、关联其他表、位置、附件、手写签名、图片。

| 场景 | 用哪种 | 判据 |
| --- | --- | --- |
| 状态、类型、等级 | 选项字段 | 启用选项 ≤6 且单选用展开型（一眼可见）；>6 或多选用下拉型并独占一行 |
| 引用另一张表的记录 | 关联其他表 | 带 2～3 个附加字段（编号、规格、单价）随选随显；单个关联字段独占一行 |
| 一单多行明细 | 子表（标签页 sub_table） | 主子表一同增删改；标签页在 bottom 或 right |
| 填写说明、板块标题 | 表单说明（separator） | 用它把长表单切成业务板块，可折叠 |
| 板块之间的视觉分隔 | 分隔符（separator2） | 只分隔不写字 |
| 谁、什么时候 | 成员、日期和时间 | 默认值已填（当前人、今天），放右侧 |
| 金额、数量 | 金额、数值 | 带单位后缀（元、件），右对齐 |
| 现场取证 | 图片、附件、手写签名、位置 | 各独占一行 |

### 按钮

- 创建或编辑表单弹窗：右上"取消、保存并继续、保存"，保存为主按钮（填充），其余描边。
- 标准表单编辑态：记录标题行右侧"取消、保存"。
- 快捷表单部件：底部"提交"主按钮；提交后有成功提示（业务语言，不写"自动化执行成功"）。

### 必填与校验

- 必填字段名后带红星。
- 至少画一处即时反馈：必填未填的红字提示或格式错误提示，不画弹窗式报错。

## 3. 布局原则

### 列数与分组

- 每行最多 4 个字段；同一分组内列数一致，字段数不能整除时末行可少（5 个字段排 2＋2＋1），不与下一组混排。
- 相邻分组的列数尽量一致，不要 1、2、3、4 列随意混排。
- 独占一行的字段：多行文本、富文本、图片、附件、手写签名、位置、多选或选项 >6 的选项字段、没有明确字段对的单个关联字段。
- 业务字段对同行：开始／结束、起点／终点、车辆／司机，不因必填状态不同拆散。
- 同组内必填行排在前，同行内必填靠左、有默认值的靠右。
- 长表单用表单说明拆成 3～6 个板块，每板块 4～12 字段；明细与关联记录收进标签页（底部或右侧）。
- 组织顺序参考：字段少用单列；短字段相关时并到一行；多类内容用板块标题分区；超过两屏拆成标签页或分步。

### 尺寸

- 字段结构：字段名在上（24 高）、灰底值框在下（32 高、圆角 6）。
- 弹窗与编辑态的整体尺寸、内边距、四列时的列间距尚未实测；画前按 c2 现有 cols-2／cols-3 比例外推，并在交付说明里注明未实测。

### 标签页位置

- 子表、关联数据、流程记录以标签页出现在表单底部（默认）或右侧；同一张表只允许一个流程记录标签页。

## 4. 数据与文案

- 字段名用业务称呼（"收货仓库"不写"仓库 ID"）。
- 已填默认值的字段显示真实值（成员＝当前登录人姓名、日期＝今天），不留空。
- 关联字段附加信息显示真实规格、单价。
- 字段数 6～18 为常态。
- 占位文字写填写提示（"请输入 11 位手机号"），不重复字段名。
- 数据毛边规则见 [anti-sameness.md](anti-sameness.md)。

## 5. 禁止项

- 一个分组内多种列数混排。
- 不定高字段与其他字段并排。
- 一泻千里的长表单不分板块。
- 需要人填的字段放右边、默认值放左边。
- 多个填充式主按钮。
- 没有用户要求就画表单弹窗或编辑态。

## 6. 检查清单

逐图回答"通过／改过（改了什么）"。

1. 用户确实要求了编辑态／表单弹窗，或表单是页面里的快捷表单部件。
2. 每行 ≤4 字段，同组列数一致，末行可少但不跨组。
3. 不定高字段（多行文本、富文本、图片、附件、多选）各自独占一行。
4. 必填带红星、靠左、在前；默认值字段已填好、靠右。
5. 长表单分了板块，明细在标签页里。
6. 只有一个填充式主按钮，其余描边。
7. 至少一处即时校验提示。
8. 交付说明注明弹窗尺寸未实测（在补齐 data-measured 之前）。
