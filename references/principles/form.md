# 表单编辑页

本文用于画表单编辑页：新建或编辑一条记录的表单（弹窗形态，表名＋取消／保存＋字段区），目标是让人从上到下一条直线填完，需要手填的靠左、能自动的靠右或不出现。字段在详情页的只读展示见 [item-detail.md](item-detail.md)，快捷表单作为页面组件的取舍见 [component-guide.md](component-guide.md) 和 [item-detail.md](item-detail.md)。用法：按第 1 节定字段类型与展示形态，第 2 节定分组、列数与填写动线。

## 1. 组件选取规则

### 按语义定类型

| 信号 | 动作 | 例子 |
| --- | --- | --- |
| 无天然唯一标识、需要独立编号；自动生成，画成只读靠右 | 用自增编号 | 合同编号、工单编号 |
| 语义是数量、金额、指标 | 用数值／金额，不用文本 | 库存数量 → 数值；合同金额 → 金额 |
| 值可枚举且固定 | 用选项，不用文本 | 优先级、状态、等级 |
| 枚举值是独立业务对象：被多张表引用、有自身属性、频繁增减、几十上百个，命中任一条 | 用关联数据，不用选项 | 供应商、客户、产品 → 关联；优先级 → 选项 |
| 引用的是外部人员，不是系统内用户 | 用关联数据，不用成员 | 供应商联系人 |
| 主从明细随主表一同增删改 | 用子表，不用关联 | 订单明细 |
| 要顺带显示被关联记录的信息 | 关联附加字段 | 订单里显示客户电话、产品规格与单价 |

### 展示形态

| 字段 | 画法 |
| --- | --- |
| 选项 | 启用选项 ≤6 且单选用展开型（一眼可见）；>6 或多选用下拉型并独占一行 |
| 关联数据 | 带 2～3 个附加字段（编号、规格、单价）随选随显；单个关联字段独占一行 |
| 子表 | 标签页形式，放表单底部（默认）或右侧 |
| 表单说明／分隔符 | 表单说明是板块标题，可折叠；分隔符只分隔不写字 |
| 成员、日期 | 默认值已填（当前人、今天），放右侧 |
| 金额、数值 | 带单位后缀（元、件），右对齐 |
| 图片、附件、手写签名、位置 | 各独占一行 |

### 按钮

- 创建或编辑表单弹窗：右上"取消、保存并继续、保存"，保存为主按钮（填充），其余描边。
- 快捷表单组件：底部"提交"主按钮；提交后有成功提示（业务语言，不写"自动化执行成功"）。

### 必填与校验

- 必填字段名后带红星。
- 至少画一处即时反馈：必填未填的红字提示或格式错误提示，不画弹窗式报错。

## 2. 布局原则

先定纵向结构（业务顺序、分组），再定行列结构（列数、独占行、字段对），最后校正填写动线；规则冲突时按末尾的优先级。

### 纵向结构

- 按实际填写或处理顺序排字段，不按重要度分层：运单日期 → 起运地／目的地 → 收入。材料没交代顺序时按该类单据的常见顺序，不臆造流程。
- 同一业务信息的字段放同一组：车辆与司机、金额与币种；组标题用表单说明；归不进任何组的放"其他信息"。
- 长表单用表单说明拆成 3～6 个板块，每板块 4～12 字段；明细与关联记录收进标签页；超过两屏拆成标签页或分步。

### 行列结构

- 每组按字段语义选 1～4 列，不预设列数；同组列数一致，字段数不能整除时末行可少（5 个排 2＋2＋1），不与下一组混排；相邻分组的列数尽量一致。
- 独占一行：多行文本、富文本、图片、附件、手写签名、位置、多选或启用选项 >6 的选项字段、没有字段对的单个关联数据。
- 业务字段对同行并按业务顺序排：开始／结束、起点／终点、车辆／司机，不因必填状态不同拆散。

### 填写动线

- 连续填写或对照查看的字段相邻：金额与币种。
- 同组内必填行排在非必填行之前；同行内必填靠左；同行只有部分字段有默认值时，要填的靠左、有默认值的靠右。

### 冲突优先级

1. 业务字段对相邻且内部顺序固定。
2. 分组顺序跟随业务流程。
3. 同组列数一致，末行可以少。
4. 必填行前置、必填字段靠左。

高优先级覆盖低优先级；不得为了必填靠左拆散字段对。

### 尺寸

- 弹窗：宽随视口减 48、高减 60（1600×891 视口下 1526×831），圆角 12，浅投影；头部 56 高，标题 16 号 500 粗；右侧按钮 32 高、圆角 6、间距 8，"保存"主色实底，"取消"白底描边，新建时多一个"保存并继续创建"分体按钮。
- 字段区：内边距 16，列宽按行宽等分，1／2／3／4 列各 1506／753／502／377；单元格内距 6，视觉列间距 12。
- 字段行 69 高：标签 24（14 号、65% 灰）＋ 值框 32（圆角 6，空态灰底、有值白底）＋ 内距 12；不定高字段空态也是 69，有值才撑高。
- 必填红星在标签后，红色；占位文字 14 号、25% 灰。分组标题行 36 高、粗体，右端折叠箭头。
- 校验：出错字段值框变浅红底，没有红边框和文字提示，焦点跳到第一个出错字段。
- 子表区在底部：圆角 6、细边框；页签行 40 高但页签字 12 号；工具栏行 48；表头 32、行 35，子表表头列名也带必填红星。
- 关联选择器：面板 360×300，头部搜索框、列表、底部按钮行。
- 新建与编辑只差标题、有无"保存并继续创建"、字段空态与有值，尺寸规格相同。

### 标签页位置

- 子表、关联数据、流程记录以标签页出现在表单底部（右侧形态官方样板里没有实例）；同一张表只允许一个流程记录标签页。

## 3. 数据与文案

- 字段名用业务称呼（"收货仓库"不写"仓库 ID"）。
- 已填默认值的字段显示真实值（成员＝当前登录人姓名、日期＝今天），不留空。
- 关联字段附加信息显示真实规格、单价。
- 字段数 6～18 为常态。
- 占位文字写填写提示（"请输入 11 位手机号"），不重复字段名。
- 数据毛边规则见 [anti-sameness.md](anti-sameness.md)。

## 4. 禁止项

- 一个分组内多种列数混排。
- 不定高字段与其他字段并排。
- 一泻千里的长表单不分板块。
- 需要人填的字段放右边、默认值放左边。
- 多个填充式主按钮。
- 没有用户要求就画表单弹窗或编辑态。

## 5. 检查清单

逐图回答"通过／改过（改了什么）"。

1. 用户确实要求了编辑态／表单弹窗，或表单是页面里的快捷表单组件。
2. 每行 ≤4 字段，同组列数一致，末行可少但不跨组。
3. 不定高字段（多行文本、富文本、图片、附件、多选）各自独占一行。
4. 必填带红星、靠左、在前；默认值字段已填好、靠右。
5. 长表单分了板块，明细在标签页里。
6. 只有一个填充式主按钮，其余描边。
7. 至少一处即时校验提示。
8. 弹窗、头部、字段行、子表区尺寸与上表一致。
