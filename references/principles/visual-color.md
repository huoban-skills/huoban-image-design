# 配色：三色原则与状态色

## 三色原则（对应"对比"）

颜色越少，重点越突出。比例：

- **60% 主色**：中性色（白、浅灰），业务系统大量底色必须是安静的
- **30% 辅助色**：可用客户品牌色，做出专属感
- **10% 提亮色**：高饱和颜色做点缀

## 状态色标准（对应"重复"）

记忆法：红绿灯，全球统一无歧义。用于选项字段、行内快捷按钮、流程节点等所有状态表达：

| 状态 | 颜色 |
|---|---|
| 成功 / 完成 / 审批通过 | 绿 |
| 进行中 / 待办 / 警告 | 橙 |
| 失败 / 危险 | 红 |
| 未开始 / 其他 | 浅灰 |
