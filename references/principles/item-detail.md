# 自定义详情页：一条记录的全貌

本文用于画自定义详情页：一条记录的查看页（官方页面类型 `item_detail`，组件默认取当前记录），回答这是哪条记录、走到哪一步了、明细与过程在哪。记录详情弹窗和表单编辑态只在用户明确要求时画，默认不套产品壳、不套弹窗。用法：先按第 1 节选版式，再按第 2 节配组件，第 3 节定色彩。

## 1. 布局原则

### 版式

从第二行起从上往下判，命中第一条就用，都不命中用第一行的默认版式。

| 版式 | 适用 | 结构（从上到下） |
| --- | --- | --- |
| 双栏式 | 默认：一条记录有字段，也有本记录的数据（数值／计算字段、指标、进度、图表）或快捷表单 | 记录功能区 → 页头卡片 → 状态条（有则放）→ 左栏字段组 13 ＋ 右栏分析区 11（官方样板 13+11 或 15+9）→ 页签容器 24 通栏（明细 → 流程 → 动态）。分析区直接竖叠本记录的数据组件（放数值／计算字段的字段组、单指标、进度条、图表），放什么按需求定，主题多时才套页签；快捷表单若有也放右栏；字段分了多组时左栏套页签容器，按"基本信息／商机"这类主题分页签 |
| 主从式 | 一条记录挂着多张关联记录（跟进、售后、购车、子表），或流程要常驻可见 | 记录功能区 → 页头卡片 → 状态条（有则放）→ 主栏 16 ＋ 从栏 8。主栏竖叠 1～2 个页签容器放子表（跟进记录／报价单、售后记录／购车记录）；从栏放字段组（多组时套页签，如客户画像／家庭成员）或流程／动态／评论页签。从栏放字段时在左（8+16），放流程时在右（16+8）；主栏叠两个页签容器用 hb-col |
| 单栏式 | 信息量很少：字段十来个、没有本记录的数据分析、关联记录 2 张以下 | 记录功能区 → 页头卡片 → 状态条（有则放）→ 字段组 24 一块通栏 → 页签容器 24 通栏（明细 → 流程 → 动态） |

版式自己定，不问用户，需求单和交付说明里不写版式名。各版式的线框示意见 [assets/layout-gallery.html](../../assets/layout-gallery.html)（浏览器打开）。

### 位置与尺寸（24 栅格；画布上边距 48、左右内缩 96、组件间距 20）

栏数和高度是样板配法与上限，按内容和画面自适应，不硬套。页签形态、层次、同排等高见 [visual-four-principles.md](visual-four-principles.md)。

| 位置 | 规则 |
| --- | --- |
| 页头卡片 | 24 通栏，高 180：标题 20/600＋副标题 14＋关键字段 |
| 状态条 | 24 通栏，高 40，箭头段；选项字段平铺是胶囊形态 |
| 字段组 | 单栏每行最多 4 字段；双栏左栏每行最多 2；同组列数一致，不定高字段独占一行（见 [form.md](form.md)） |
| 双栏／主从 | 两栏顶齐、等高，短的一侧补内容（分析区补一块统计，字段组补一组字段，主栏补一个页签容器），不用固定高度硬撑，栏内不留大片空白 |
| 页签容器 | 高 36～55；页签按"发货／排产／回款"这类业务分，分析区套页签时按"交付／回款"这类主题分，过程区页签流程在前；页签内放表格列表 24×16 竖叠 2～3 张，或单指标 8×6 ×3＋表格，可放字段组、表格列表、单指标、流程；多张子表时底部页签容器每个子表一页，页签名可带图标 |
| 同构子卡 | 8＋8＋8，一组同类卡片（多张附件、多个联系人） |
| 浮层 | 营销图浮层只从右侧探出（详情页没有左侧导航，左探会压住页头与左栏） |

## 2. 组件选取规则

| 记录要回答的问题 | 组件 | 必有／可选 | 数量与取舍 |
| --- | --- | --- | --- |
| 我能对它做什么 | 记录功能区（产品自带：记录标题＋业务快捷按钮＋编辑／复制／分享／打印／历史／更多／关闭） | 必有，顶部 | 快捷按钮 1～3 个，实底／线框／置灰三态可并存 |
| 这是哪条记录 | 页头卡片 | 必有，首位 | 1；信息字段 1～4 个；不放按钮 |
| 走到哪一步了 | 状态条（箭头式，可点切换）；或选项字段平铺（胶囊式，只展示） | 有状态流转的单据建议放 | 1 |
| 详细信息、明细、过程各在哪 | 标签页 | 必有，承载主体 | 1～3 个容器，每个 1～4 页签 |
| 记录的字段 | 字段组 | 必有 | 1 个主字段组 ＋ 0～2 个小字段组 |
| 明细行（子表） | 表格列表 | 有主子表时必有 | 列 4～8，行数少于一屏 |
| 审批与协作过程 | 流程执行记录／动态／评论 | 有流程的表必有流程；动态与评论可选 | 各 1 |
| 就近录入 | 快捷表单 | 可选 | 1；放右栏分析区下方 |
| 这条记录的数据分析 | 字段组（数值／计算字段）／单指标／进度条／图表（折线、面积、柱状、条形、双轴，选型查辞典四章） | 可选 | 组件与个数按需求定，只放与本记录相关的数；全部放右栏分析区 |

选图表类型或拿不准该用哪个组件时，查 [component-guide.md](component-guide.md)。

## 3. 色彩

- 状态条：已过段主色 25% 底、当前段主色实底白字、未来段白底灰字。
- 流程节点状态：执行中橙、同意绿、驳回红。
- 快捷按钮三态：主动作实底、次动作线框、不可用置灰；同一功能区只有一个实底。
- 颜色只走皮肤 token，见 [../skin/routing.md](../skin/routing.md)。

## 4. 数据与文案

- 页头标题写记录本身（单号＋客户、设备名＋编号），副标题放编号或类型；关键字段选决定业务动作的字段（状态、金额、负责人、日期）。
- 字段总数 6～18 为常态，超过就拆页签。
- 子表行数 5～12，带一处非理想态（缺件、超期、驳回）。
- 流程节点倒序、带耗时；至少一个节点是"执行中"或"驳回"，不全是同意。
- 数据毛边规则见 [anti-sameness.md](anti-sameness.md)。

## 5. 禁止项

- 页头卡片放按钮。
- 套产品壳、一级顶栏、左侧导航、弹窗遮罩（除非用户明确要弹窗）。
- 详情页放横幅、筛选、与本记录无关的图表。

## 6. 检查清单

逐图回答"通过／改过（改了什么）"。

1. 顶部是记录功能区，页头卡片紧随、通栏、无按钮。
2. 有状态流转的单据带状态条，当前段唯一。
3. 主体是页签容器，1～3 个，每个 1～4 页签，容器不套容器。
4. 左栏字段、右栏分析区，两侧底边齐；页签容器通栏在两栏之下。
5. 字段组每行 ≤4（双栏时左栏 ≤2）、同组列数一致、不定高字段独占一行。
6. 有流程的表带流程页签且在动态、评论之前。
7. 没有横幅、筛选、与本记录无关的图表、按钮组。
8. 通用项（数据像真的、浮层只放底层没有的内容且只从右侧探出、对齐）按 [../canvas/verify-export.md](../canvas/verify-export.md) 的十条表。
