# 界面设计原则（索引）

来源：伙伴云生态训练营三阶段课程逐字稿（视觉设计、交互设计、数据看板三讲，2026-08-07 整理）；workbench 与 dashboard-layout 另含交付经验与通用资料，文内标注。

总纲：界面层是系统的驾驶舱，数据层/逻辑层/集成层是发动机。用户先为驾驶舱买单。
- **好看＝视觉设计**，判据四条：对齐、亲密性、对比、重复
- **好用＝交互设计**，判据三条：清晰引导（不让用户迷路）、高效省力（不让用户费力）、即时反馈（不让用户犯错）
- **看板＝讲数据故事**，判据三问：发生了什么、为什么会这样、我该怎么办
