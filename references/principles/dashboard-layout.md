# 数据看板：指标到部件、区块布局

来源：课程判据（三问、指标体系，见 dashboard-data-story.md；分析方法到图表，见 dashboard-chart-selection.md）＋ 通用看板设计资料（倒金字塔、主指标左上、单屏 5～9 个指标）＋ 交付经验（单指标只放一行、环图并排，2026-09-04 定）。本文只管"选哪个部件、放哪"，定位和指标怎么拆不重复。

## 指标到部件

| 指标类型 | 部件 | 规则 |
| --- | --- | --- |
| 北极星/结果指标 | 单指标-居中大数 | 1 个主指标＋2～4 个结果指标，一行放完，放最顶行；必带对比（目标、同比、环比），没对比的数字不上看板 |
| 过程指标 | 多进度条、统计表、柱状图 | 从结果指标拆出来的；不再用单指标卡另起一排 |
| 趋势 | 折线/柱状（图表部件） | 主指标必配一张趋势图，在左侧、面积最大 |
| 对比维度 | 柱状、分类小计、统计表 | 按人/区域/产品切片，放趋势图右侧或下一行 |
| 构成 | 环图 | 两张并排成一行（如按仓库、按品类），或与对比柱图并排；不单独占一整行 |
| 明细/异常清单 | 表格列表、统计表 | 放最底部，是"我该怎么办"的落点；只列异常，不列全部 |
| 范围切换 | 筛选部件 | 放横幅正下方，全局生效；筛选项 2～4 个 |

## 布局

- 倒金字塔，从上到下对应三问：横幅 → 筛选 → 结果指标一行（发生了什么）→ 趋势图＋对比图或环图一行（为什么）→ 明细表（怎么办）。
- 单指标只放一行，4～6 个；两排单指标是信息过载的标志。
- 主指标放左上，趋势图占一行的 16 栏或 2/3。
- 单屏指标卡加图表不超过 9 个。
- 深底大屏只在用户明确要"大屏"或"大屏模式"时做；报告配图默认浅底。
- 层次默认白底描边。

## 大屏模式

大屏＝看板加深色背景和装饰框，指标和图表的选取规则不变，只加四条：

- Z 型一屏放完：顶部标题条，上排结果指标 6～8 个，中间大视觉位（3D 场景/地图）或主趋势图，两侧各一列图表卡，底部播报表或明细。不滚动，超出就删。
- 一张图只选一种主题、一种背景、一种装饰框、一种标题条，不混搭。
- 指标值大字 32 居中，指标名放上面，一行放完，仍然要有对比（同比/目标）。
- 客户没有 3D 图或地图时中央视觉位留光晕地台，不画灰图标；企业名放标题条左上。

## 检查

- 顶行每个数字旁边有对比值或趋势条。
- 从上到下能读出一段故事：现状 → 问题在哪 → 该做什么。
- 单指标只有一行；环图不是孤零零一张。
- 明细表里有异常态（超期、低于下限、驳回），不是清一色正常。
