# 工作台：一个角色的工作入口

来源：伙伴云生态训练营课程判据（卡片布局、亲密性、重复）＋ 交付经验（角色切分、部件取舍、首屏顺序，2026-09-04 定）＋ Ant Design 数据展示规范（卡片一行最多四个）。部件名以 assets/c3-page-detail.html 收录为准。

## 定位

- 工作台是某个角色一天工作的入口，回答"我要做什么、从哪进、我现在要处理什么"。判据：这个角色不点左侧导航就能完成当天大部分动作。
- 工作台是让人动手的，看板是让人看出道道的，两者不混做。工作台上的数字只为引导动作（待办 3 条、本月完成 12 单），不做分析，不放趋势图和对比图。
- 一个工作台只服务一个角色（库管、销售、店长、审批人）。角色不同，部件不同；给"所有人"做的工作台等于没人用。

## 部件选取：按角色的问题取

先列这个角色一天要回答的问题，再对号选部件。问题不成立的行不放。

| 角色的问题 | 部件 | 取舍 |
| --- | --- | --- |
| 这页管什么、给谁用 | 横幅（页面名＋一句话介绍） | 必有，首屏第一位 |
| 我要发起什么 | 快捷方式、快捷按钮 | 必有，3～6 个，按使用频次排，不凑数 |
| 我现在要处理什么 | 待办/流程任务子区、我发起的流程 | 有流程的角色必有，与快捷入口同屏 |
| 我的事按什么顺序做 | 页签容器 | 页签按角色的工作流程从左到右编排（接单→备料→生产→交付），或按业务分类；页签居中 |
| 今天/本周安排 | 日历（带日程/单月）、日期时间 | 有排期的角色才放（巡检、拜访、排产、跟进） |
| 我名下的数据 | 表格列表（按人筛过的视图） | 放"我的"不放"全部"，条数少于一屏 |
| 我的成绩到哪了 | 单指标、多项汇总 | 2～4 个，只放这个角色对结果负责的数 |
| 收集数据 | 快捷表单 | 门户型工作台才放（报修、报名、留资），角色工作台不放 |
| 公告/通知 | 富文本、图文列表、轮播图 | 门户型才放 |

## 布局

- 卡片布局：相关操作放同一容器，间距统一、同组同色。
- 首屏顺序固定：横幅 → 快捷入口与待办同屏（快捷方式 8 栏在左或横幅右侧直接放快捷按钮，待办 16 栏）→ 页签容器或我的数据/日程 → 指标。
- 单指标一行不超过 4 个，只放一行。
- 整页不超过两屏。超了说明角色没切干净，拆成两个工作台。
- 层次默认白底描边；营销图要突出时改浅底白卡。

## 检查

- 这页是给哪个角色的，能一句话说出来。
- 每个部件都对应上表某一行的问题；对不上的删。
- 快捷入口在待办之前或同屏，不在页面底部。
- 没有趋势图、对比图、环图；有就挪去看板。
